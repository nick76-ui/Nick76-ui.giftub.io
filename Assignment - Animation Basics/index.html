Exit Ticket Answers

  1. Transition 2px lift: transition: transform 200ms ease, box-shadow 200ms ease;
  2. Transform/Opacity: Use when you need smooth performance - they don't cause layout changes
  3. Reduced motion: @media (prefers-reduced-motion: reduce) { * { animation: none; } }

Part A: Concepts

  1. CSS Transition: Changes from one value to another over time. Four parts: property, duration, timing-function, delay. Example: transition: all 0.3s ease-in-out;
  2. Transition vs @keyframes: Transitions go from A to B once. Keyframes can go A→B→C→A and repeat. Use transition for simple hover effects, keyframes for complex animations.
  3. Transform-origin: Sets the point around which transform happens. Example: transform-origin: top left;
  4. Timing functions: ease (smooth start/end), linear (constant speed)

Part C: Reflection

Motion improved understanding when showing interactive feedback like button presses and hover states. Motion distracted when animations were too fast or flashy. The 200ms duration with ease timing felt best for hover effects. For accessibility, I included reduced motion support to respect users who prefer less animation.
