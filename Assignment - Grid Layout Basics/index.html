Assignment - Grid Layout Basics

Part A - Concepts

1) Grid Container, Items & Tracks
Container is the parent. Items are children. Tracks are rows and columns.

2) FR Unit vs Percentages
FR divides space equally. Percentages don't account for gaps.

3) Repeat() & Minmax()
repeat(3, 1fr) makes 3 columns. minmax(200px, 1fr) makes min 200px, max 1fr.

4) Auto-fill vs Auto-fit
auto-fill creates empty columns. auto-fit stretches items to fill space.

5) Grid-column & Grid-row
grid-column: 1 / 3 spans columns. grid-row: 1 / 3 spans rows.

6) Grid-template-areas
Names grid areas so you can place items by name instead of numbers.

7) Justify-items vs Align-items
justify-items aligns left-right. align-items aligns top-bottom.

8) Grid-auto-flow: Dense
Fills empty gaps by moving items. Don't use it often.
